# NAQAA Field Lab — مختبر نقاء الميداني

واجهة أولية عربية لتوثيق المواقع والملاحظات والصور الميدانية، مع إرفاق إحداثيات بموافقة المستخدم، ومعاينة خريطة شوارع أو صور فضائية.

## تشغيل النسخة

- افتح `index.html` في متصفح حديث للمعاينة الأساسية.
- للحصول على إذن الكاميرا والموقع، انشر المجلد عبر HTTPS أو شغّله على `localhost`؛ كثير من المتصفحات تمنع هذه الميزات عند فتح ملف محلي مباشرة.
- تعتمد الخريطة على اتصال الإنترنت وخدمات خرائط خارجية. قد لا تظهر إذا حُجبت الخدمات.
- السجلات والصور محفوظة داخل IndexedDB في المتصفح نفسه، ولا تُرسل إلى خادم.
- صدّر نسخة JSON احتياطية بانتظام. مسح بيانات المتصفح قد يحذف السجلات المحلية.

## الموجود في النسخة 0.1.0

- واجهة عربية متجاوبة.
- طلب الموقع فقط عند ضغط المستخدم على زر «تحديد موقعي».
- طلب الكاميرا فقط عند ضغط المستخدم على زر «فتح الكاميرا»، مع التقاط صورة وإيقاف الكاميرا.
- إرفاق صور من الجهاز.
- إنشاء سجلات بمعلومات الموقع والتصنيف والإحداثيات والملاحظات والقياسات والصور.
- عرض السجلات على الخريطة عند توفر إحداثيات.
- حفظ محلي، وحذف سجل أو تصدير سجل/كل السجلات بصيغة JSON.

## ما لم يُنفّذ بعد

هذه النسخة ليست منصة تحليل علمي آلي ولا تستنتج آثارًا أو دفائن أو مياهًا جوفية. لم تُربط بعد بنموذج رؤية حاسوبية، أو كتالوج مراجع أثرية، أو بيانات ارتفاع رقمية، أو محرك تضاريس ثلاثي الأبعاد، أو قارئ ملفات GPR/ERT. طبقة الصور الفضائية للمعاينة البصرية فقط.

المرحلة التالية تتطلب إضافة وحدات تحليل موثوقة ومصادر بيانات مرخصة، وإظهار المصدر ودرجة الثقة والقيود لكل نتيجة. لا تُستخدم المخرجات وحدها لاتخاذ قرار أثري أو هندسي.

## الخصوصية والسلامة

- لا تطلب الواجهة أذونات الموقع أو الكاميرا تلقائيًا.
- رفض الإذن لا يمنع إدخال الإحداثيات يدويًا.
- لا تضع كلمات مرور أو مفاتيح API أو بيانات حساسة في ملفات Git.
- لا ترفع صورًا خاصة إلى خدمات خارجية دون موافقة صريحة.


## الاشتراكات — تصميم أولي

توجد واجهة باقات أولية؛ أسعار الباقات الواردة أدناه هي القيم المعتمدة في كود الإصدار الحالي، ويجب تأكيدها تجاريًا قبل استقبال المدفوعات:

|---|---:|---:|---:|
| تجربة مجانية | $0 | موقعان | 10 إجمالًا |
| يومية | $10 | موقعان خلال مدة الاشتراك | 20 يوميًا |
| أسبوعية | $50 | 10 مواقع خلال 7 أيام | 100 خلال الأسبوع |
| شهرية | $100 | 30 موقعًا خلال 30 يومًا | 300 خلال الشهر |

يحتسب الخادم الحصص، وأضيفت واجهات طلب الدفع والتحقق من USDT على شبكة TRON وتفعيل الاشتراك بعد التحقق. تظل المدفوعات الحقيقية مغلقة افتراضيًا، ولا تفتح حتى نشر API على HTTPS وربطه بقاعدة PostgreSQL دائمة وعنوان استقبال موثوق ومفتاح مزود الشبكة. لا تُعرض وحدة التحليل العلمي كخدمة مكتملة؛ التحليل الآلي غير منفذ في هذا الإصدار.


## API backend — أول مرحلة للحسابات والحصص

أُضيف مجلد `api/` داخل المشروع مع API أولي لتسجيل الحسابات وتسجيل الدخول، وتخزين الحسابات في قاعدة بيانات SQLAlchemy، وتجزئة كلمات المرور، ورموز دخول قصيرة الأجل، وعرض الحصة واحتساب الاستهلاك من جهة الخادم. كما أُضيفت واجهة أولية للحساب والحصة.

**قبل التجربة:** راجع `api/README.md`، ثبّت المتطلبات، شغّل الخادم، ثم اضبط `FIELD_LAB_API_BASE` في `api-config.js` على عنوان HTTPS المنشور. لا تُدخل بيانات حقيقية قبل إعداد HTTPS وسر قوي ومراجعة الأمان.

**قبل الإطلاق العام:** نشر API على HTTPS وقاعدة PostgreSQL دائمة، ضبط المتغيرات السرية في مزود الاستضافة، التحقق من عنوان SafePal، ضبط `FIELD_LAB_API_BASE` في `api-config.js` بعنوان الخادم المنشور، إضافة التحقق من البريد/استعادة كلمة المرور، ثم اختبار المستخدم النهائي على أجهزة حقيقية. الدفع الحقيقي يبقى مغلقًا ما دام `/payments/status` لا يعيد `payments_enabled: true`.


## مشاركة التطبيق وتوزيعه

- قسم المشاركة في الواجهة يشارك رابط الصفحة الحالية عبر قائمة المشاركة في الهاتف أو WhatsApp أو Telegram أو Facebook.
- يجب أن يكون الموقع منشورًا على HTTPS كي يصل الآخرون إلى الصفحة؛ فتح `index.html` محليًا لا ينشئ رابطًا عامًا.
- لتوزيع APK عبر Bluetooth أو Quick Share: نزّل APK النهائي الذي تم التحقق من نجاح بنائه، ثم من تطبيق الملفات على Android اختر الملف ← مشاركة ← Bluetooth أو Quick Share.
- ملف APK يعمل على Android فقط. أجهزة iPhone تحتاج نسخة iOS موقّعة وموزعة بالطريقة المناسبة، أو استخدام نسخة ويب متوافقة.
- لا تُوزّع ملف Debug على أنه إصدار إنتاج. يلزم بناء إصدار Release موقّع ومراجعة الأذونات والتوافق والأمان قبل التوزيع العام.


## معاينة عبر Chrome

بعد نجاح نشر GitHub Pages، افتح رابط الموقع المنشور عبر HTTPS من هاتفك. لا تُدخل بيانات دفع حقيقية في النسخة التجريبية؛ الاشتراكات والمدفوعات الحقيقية غير مفعّلة.
