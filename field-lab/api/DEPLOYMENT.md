# NAQAA Field Lab API deployment checklist

This API must be deployed to a managed HTTPS service with a persistent PostgreSQL database before accepting payments. Do not set payment activation to true until all chain-validation and replay/idempotency tests have passed.

## Required server environment

- `FIELD_LAB_ENV=production`
- `FIELD_LAB_JWT_SECRET`: long random secret, generated by the hosting provider or a password manager; never commit it.
- `FIELD_LAB_DATABASE_URL`: managed PostgreSQL connection URL with persistent storage and backups. Do not use SQLite for production.
- `FIELD_LAB_TRON_USDT_RECEIVE_ADDRESS`: the intended public TRON receive address.
- `TRONGRID_API_KEY`: API key stored as a host secret.
- `FIELD_LAB_PAYMENTS_ENABLED=false` until payment verification is independently tested.
- `FIELD_LAB_TRON_USDT_CONTRACT=TXLAQ63Xg1NAzckPwKHvzw7CSEmLMEqcdj` only after independently confirming this is the official USDT TRC20 contract on TRON mainnet.
- `FIELD_LAB_ALLOWED_ORIGINS`: exact HTTPS origin(s) for the hosted client.

## Deployment

Build from this directory using `Dockerfile`, run the health check at `/health`, and configure HTTPS at the hosting platform. Attach a persistent PostgreSQL database before first production traffic. Configure backups and alerting.

## Payment launch gate

Do not accept mainnet funds until a reviewer verifies: confirmed mainnet transaction only; official token contract; recipient address; exact integer token amount/decimals; transaction finality; and database-level atomic idempotency under concurrent requests. Test wrong recipient, wrong token, wrong amount, unconfirmed/reverted transactions, reused transaction IDs, concurrent confirmations, and provider timeouts. The current API's database uniqueness constraint helps reject duplicate transaction IDs, but by itself is not a complete concurrency-safe payment ledger.

## Android signing

Generate the Android upload/release keystore on a trusted device you control, keep a secure offline backup, and never commit it to Git. In repository Settings → Secrets and variables → Actions, add these repository secrets:
- `ANDROID_KEYSTORE_BASE64`: base64 encoding of the keystore file.
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Do not share the passwords or keystore with anyone. Then open Actions → “Build NAQAA Field Lab Signed Android Release” → Run workflow. Confirm the run succeeds and verify the APK signer before distribution. A build artifact is not proof that the payment service is live.
