# سوق نقاء Buy&Sell وسبيل عطاء الخيري

هذا مستودع مستقل منفصل عن المشروع الأول، ومبني على النسخة المتقدمة منه لاختصار وقت التطوير.

- **سوق نقاء Buy&Sell:** سوق للعقارات والمستلزمات والخدمات والحلول المستدامة.
- **سبيل عطاء الخيري:** مساحة مستقلة للمبادرات والعطاء الخيري.
- الحسابات والتسعير والمحفظة والمالية والإدارة والبنية المحمولة موروثة من النسخة المتقدمة.

المشروع الأول يبقى مستقلاً ولا يتم تعديله من خلال هذا المستودع.
